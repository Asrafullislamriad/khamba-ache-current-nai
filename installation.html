ESP8266-এ ফার্মওয়্যার ফ্ল্যাশ করুন

USB ক্যাবল দিয়ে ESP8266 কম্পিউটারে কানেক্ট করুন, তারপর নিচের বাটনে ক্লিক করুন — ব্রাউজার থেকেই সরাসরি ফ্ল্যাশ হয়ে যাবে!

ব্রাউজার থেকে সরাসরি ফ্ল্যাশ করুন

  1. USB ক্যাবল দিয়ে ESP8266 কম্পিউটারে লাগান।
  2. নিচের "Flash Firmware" বাটনে ক্লিক করুন।
  3. পপআপে আপনার ESP8266 এর COM Port সিলেক্ট করুন।
  4. ফ্ল্যাশ শেষ হলে ESP নিজে থেকে রিবুট হবে!
আপনার ব্রাউজার Web Serial সাপোর্ট করে না। দয়া করে Google Chrome বা Microsoft Edge ব্যবহার করুন।
HTTPS প্রয়োজন। এই পেইজটি https:// দিয়ে খুলুন।
Chrome বা Edge ব্রাউজার লাগবে। Firefox/Safari এ Web Serial কাজ করে না।
COM Port দেখা যাচ্ছে না? আপনার কম্পিউটারে CH340 Driver ইনস্টল করতে হতে পারে। গুগলে "CH340 driver download" লিখে সার্চ করুন।
৩

WiFi সেটআপ করুন

ফ্ল্যাশ হওয়ার পর ESP নিজে থেকে একটি WiFi Hotspot তৈরি করবে। সেখান থেকে আপনার WiFi সেটআপ করুন।

  1. ফ্ল্যাশ করার পর ESP রিবুট হবে এবং "PowerPulse-Setup" নামে একটি WiFi Hotspot তৈরি হবে।
  2. আপনার মোবাইল বা কম্পিউটার দিয়ে "PowerPulse-Setup" WiFi তে কানেক্ট করুন।
  3. একটি পেইজ অটোমেটিক খুলবে (Captive Portal)। না খুললে ব্রাউজারে 192.168.4.1 লিখুন।
  4. পেইজে আপনার Device ID দেখাবে — "Copy" বাটন চেপে কপি করে রাখুন!
  5. "Configure WiFi" চাপুন → আপনার বাসার WiFi নাম সিলেক্ট করুন → পাসওয়ার্ড দিন → "Save" চাপুন।
  6. ESP রিবুট হয়ে আপনার WiFi তে কানেক্ট হবে। হয়ে গেছে! 🎉
Device ID কপি করেছেন তো? পরের ধাপে Dashboard এ এই ID দিয়ে register করতে হবে!
WiFi পরিবর্তন করতে চান? ESP এর RST বাটন ৩ বার দ্রুত চাপুন — আবার "PowerPulse-Setup" hotspot তৈরি হবে।
৪

ড্যাশবোর্ডে রেজিস্টার করুন

  1. ESP8266 কম্পিউটার থেকে খুলে নিন।
  2. একটি মোবাইল চার্জার দিয়ে ESP8266-কে দেওয়ালের প্লাগে লাগান।
  3. PowerPulse ড্যাশবোর্ড-এ গিয়ে "+ Add Monitor" বাটনে ক্লিক করুন।
  4. আপনার এলাকার নাম লিখুন এবং WiFi সেটআপের সময় যে Device ID কপি করেছিলেন সেটি paste করুন।
অভিনন্দন! আপনার লোডশেডিং মনিটর চালু হয়ে গিয়েছে! কয়েক মিনিটের মধ্যেই ড্যাশবোর্ডে আপনার এলাকার কারেন্টের অবস্থা দেখা যাবে।

ড্যাশবোর্ড কিভাবে দেখবেন

  • সবুজ কার্ড = ওই এলাকায় এখন কারেন্ট আছে
  • লাল কার্ড = ওই এলাকায় এখন লোডশেডিং চলছে
  • যেকোনো কার্ডে ক্লিক করলে ডান পাশে পুরো হিস্ট্রি দেখা যাবে — কখন কারেন্ট গিয়েছিলো, কখন এসেছে, কতক্ষণ ছিল না
  • ফিল্টার বাটন (All / Power On / Load Shedding) দিয়ে আলাদা আলাদা ভাবে দেখুন

সচরাচর জিজ্ঞাসা

প্রতি মাসে কত বিদ্যুৎ বিল বাড়বে?
ESP8266 মাত্র ০.০৭ ওয়াট বিদ্যুৎ খরচ করে। পুরো মাসে ১ টাকারও কম বিল যোগ হবে!
WiFi ছাড়া কি কাজ করবে?
না। কিন্তু লোডশেডিং হলে WiFi Router-ও বন্ধ থাকে — সেটাকেই আমাদের সিস্টেম "লোডশেডিং" হিসেবে ধরে। তাই এটি Feature, Bug নয়!
একাধিক এলাকা মনিটর করতে চাইলে?
প্রতিটি এলাকায় আলাদা ESP8266 বসান। প্রতিটির নিজস্ব unique Device ID থাকবে। সব এলাকা একটি ড্যাশবোর্ডেই দেখা যাবে!
WiFi পাসওয়ার্ড পরিবর্তন করলে?
ESP8266 এর RST বাটন ৩ বার দ্রুত চাপুন — আবার "PowerPulse-Setup" hotspot তৈরি হবে। সেখানে নতুন WiFi সেটআপ করুন।
Device ID হারিয়ে গেলে?
ESP রিসেট করলে (RST ৩ বার) WiFi portal এ আবার Device ID দেখাবে। কপি করে নিন!
